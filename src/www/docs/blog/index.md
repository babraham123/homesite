# Bket's Blog

The homelab docs cover *how* things are configured. This is where I write about *why*: the design tradeoffs, the ideas that didn't pan out, and the bugs that took a weekend to track down.

Posts are grouped by category, so that's the quickest way to find a topic. To follow along, subscribe to the [RSS feed](https://bket.net/feed_rss_created.xml). Every post has a comment section if you want to tell me I'm wrong.
